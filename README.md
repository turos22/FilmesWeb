# 🎬 FilmesWeb

O **FilmesWeb** é uma aplicação web desenvolvida para a listagem, consulta e gerenciamento de filmes e produções cinematográficas, proporcionando uma interface simples e intuitiva para os usuários.

---

## 📌 Funcionalidades Principais

* 🔍 **Consulta de Filmes:** Navegação por catálogo de filmes com detalhes como título, sinopse, gênero e ano de lançamento.
* ➕ **Cadastro e Edição:** Funcionalidade de CRUD (Create, Read, Update, Delete) para gerenciamento do acervo.
* 🏷️ **Categorização:** Organização e filtragem por gêneros e categorias.
* 📱 **Interface Responsiva:** Layout adaptável para dispositivos móveis e desktops.

---

## 🛠️ Tecnologias Utilizadas

* **Front-end:** HTML5, CSS3, JavaScript
* **Back-end / Banco de Dados:** Java / MySQL / Node.js
* **Ferramentas:** Git e GitHub

---

## 🚀 Pré-requisitos e Como Executar

### Pré-requisitos
* Navegador web moderno (Chrome, Firefox, Edge, Safari).
* Servidor local caso haja integração com backend/banco de dados (ex: Live Server do VS Code, Apache/XAMPP, ou ambiente Java/Node).

### Passos para execução

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/turos22/FilmesWeb.git
   ```

2. **Acesse o diretório do projeto:**
   ```bash
   cd FilmesWeb
   ```

3. **Execução:**
   * Caso seja uma aplicação estática (HTML/CSS/JS), basta abrir o arquivo `index.html` diretamente no seu navegador ou utilizar a extensão **Live Server** no VS Code.
   * Se houver dependências de backend, certifique-se de compilar/iniciar o servidor correspondente antes de acessar.
